## [2620. Counter](https://leetcode.com/problems/counter/?envType=study-plan-v2&envId=30-days-of-javascript)
**Difficulty: Easy** | **Topic: Closure** 

In the early days of JS, OOP was not support so people used functions and closure to get around that.

> To understand more about **closure**, read the first problem [1. create hello world fucntion](./1.%20Create%20Hello%20World%20Function.md)

There is not much to be said for this solution. See solution below:
```js
/**
 * @param {number} n
 * @return {Function} counter
 */
const createCounter = function(n) {
    
    return function() {
        return n++;
    };
};

/** 
 * const counter = createCounter(10)
 * counter() // 10
 * counter() // 11
 * counter() // 12
 */
```
